# Voting Machine in Python

A beginner-friendly command-line voting machine built with Python. The program checks voting eligibility, displays party choices, validates user input, and confirms the selected option.

## Features

- Checks whether a voter is at least 18 years old
- Handles invalid age and choice input without crashing
- Displays party choices using a dictionary
- Uses functions to keep the code organized
- Includes NOTA (None of the Above) as an option

## How to Run

1. Install Python 3.8 or newer.
2. Clone this repository:

       git clone https://github.com/arth0040/voting-machine-python.git

3. Open the project folder:

       cd voting-machine-python

4. Run the program:

       python voting_machine.py

## What This Project Demonstrates

This project is a practical example of Python fundamentals, including variables, input handling, type conversion, conditionals, loops, dictionaries, functions, exception handling, and formatted strings.
